## Reproducible acquisition and preparation

The MATLAB R2019a entry point is
`code/data_preparation/prepare_all_official_data_R2019a.m`. It uses the official
Columbia CAVE archives for COIL-20/100, the MNIST creator host with the
creator-authorized CVDF mirror as a fallback, and the NEU-hosted Google Drive
file. It never downloads PIE or YaleB from an unofficial mirror or bypasses a
provider access gate.

The recovered MNIST row-selection file contains 6996 integer indices only. It
was generated by exact pixel-and-label matching of the author matrix against
all 70,000 official MNIST samples. MATLAB R2019a regeneration produced exact
`fea` and `gnd` equality for MNIST_Han and COIL20. The historical COIL100, PIE,
and YaleB feature matrices do not contain the original filenames or full
preprocessing metadata, so the deterministic converters validate dimensions,
labels, finiteness, and nonnegativity but do not claim byte identity.

The NEU-CLS wrapper was also run on the 1800 official images in MATLAB R2019a.
The regenerated 32-by-32 matrix differed from the archived feature values by at
most `7.22e-15`, consistent with floating-point roundoff. The regenerated LBP
matrix was structurally valid but not element-wise identical to the archived
LBP matrix, so no exact-equality claim is made for that derivative.

## Optdigits attribution and modification notice

Original dataset: E. Alpaydin and C. Kaynak, *Optical Recognition of
Handwritten Digits*, UCI Machine Learning Repository, 1998,
<https://doi.org/10.24432/C50P49>, CC BY 4.0. The included MAT file combines the
official training and test partitions and stores the features as rows in `fea`
with labels in `gnd`; the underlying 64 integer-valued features are unchanged.
